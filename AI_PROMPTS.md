# Important AI Prompts Used

These are the key prompts used as part of the Week 5 AI-assisted development workflow.

## 1. Requirements and architecture
> Build a small Python command-line Personal Expense Tracker for a beginner-friendly internship project. It should add expenses, list expenses, calculate total spending, show category totals, store data locally in JSON, and have clear functions. Keep the design simple and explain the structure.

## 2. Code generation
> Generate the Python implementation for the requirements above. Use only the Python standard library. Include input validation, file handling, and a simple CLI menu. Keep functions small and readable.

## 3. Code explanation
> Explain the purpose of each function in this Python expense tracker and explain how JSON loading/saving and exception handling work. Assume I am a junior developer.

## 4. Debugging
> Review this expense tracker code and identify at least one realistic bug or reliability issue. Explain why it happens, provide a minimal fix, and suggest a test that would catch it. Do not rewrite unrelated parts of the application.

## 5. Validation and error handling
> Review the application input validation. Identify missing validation cases and suggest simple error handling for invalid amounts, empty text, and corrupted JSON data.

## 6. Testing
> Generate basic unittest test cases for the expense tracker. Cover valid input, invalid input, adding an expense, total calculation, category totals, file persistence, and invalid JSON.

## 7. Documentation
> Create a concise README for this Python Personal Expense Tracker. Include features, requirements, how to run the application, how to run tests, project structure, validation, and how AI was used.

## 8. Final code review
> Perform a final code review of this expense tracker as a senior Python developer. Check correctness, readability, error handling, validation, testing, security, and maintainability. List only actionable improvements that a junior developer can understand and verify.
